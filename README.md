# Odoo Telegram AI Assistant

Bot Telegram berbasis AI untuk membantu pemilik toko memantau bisnis melalui Odoo.

## Fitur

- 📦 Cek stok barang
- 💰 Cek harga jual dan harga modal
- 📊 Cek omset harian/mingguan/bulanan
- 📈 Laporan laba rugi
- 🤖 Didukung AI Groq untuk analisis natural language

## Requirement

- Python 3.10+
- Odoo 17
- Telegram Bot Token
- Groq API Key

## Instalasi

1. Clone repo
2. Install dependencies: `pip install -r requirements.txt`
3. Copy `.env.example` ke `.env` dan isi kredensial
4. Jalankan: `python main.py`
